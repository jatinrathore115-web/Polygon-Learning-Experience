# Source material and previous artwork

These files are kept for editing and reference. The game does not load this folder, and it is excluded from deployment.

- `legacy-ui/`: previous backgrounds, board, instruction panel, and guide images.
- `swiftee-assets/`: original character pack used by `node build-swiftee.cjs`.
- `uploads/`: source lesson PDFs and uploaded reference images.
- `figs/`: local working figures and screenshots (ignored by Git).

Current game artwork lives in `../assets/`. See `../STRUCTURE.md` for the lesson screen map.
